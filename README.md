# Demo landing — studio nutrizionistico

Sito dimostrativo in pagina singola (HTML/CSS statico, nessuna dipendenza).
Serve come prova da mostrare a potenziali clienti: il nome e' generico, si riusa cambiando i valori nel blocco `:root` di `index.html`.

- `index.html` — la pagina completa
- `img/` — le immagini (licenze libere CC0, da sostituire con quelle reali del cliente)
- `robots.txt` — esclusione dai motori di ricerca (demo non indicizzata)

## Ri-brandizzare per un cliente
1. aprire `index.html`
2. modificare il blocco `:root` in testa: nome, citta', telefono, WhatsApp, email, indirizzo, orari, albo, P.IVA
3. sostituire le immagini in `img/`
